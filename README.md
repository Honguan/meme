# MEME CLASH / 迷因亂鬥

免費、開源的 2D 物理碰撞卡牌遊戲。用迷因組成卡組，在不同場地連鎖效果，或在自由沙盒自行創作。

[立即遊玩](https://meme-clash-honguan.zippy-goose-5321.chatgpt.site) · [原始碼](https://github.com/Honguan/meme)

## 開始遊玩

首頁直接進入人機對決。點擊手牌查看效果並召喚／發動；完成部署後按「開始碰撞」。角色由 Matter.js 模擬碰撞，傷害依卡牌、陷阱及陣營連攜共同結算。

對決包含攻擊軌跡、命中衝擊波、短暫命中停頓、生命／護盾淨變化數字、陷阱連鎖提示及 K.O. 演出。陣營特效分別使用 BONK、火焰、愛心、金幣、大腦文字與 404 錯亂；最後一擊演出結束後才切換回合。系統啟用「減少動態效果」時，保留結果文字，關閉震動、軌跡、命中停頓及擴散動畫。特效不改變傷害規則。

右上角調色盤可切換萊姆電光、珊瑚熱浪、冰河藍綠 3 種色系，介面與雙方角色外框同步更新。色系獨立保存在目前瀏覽器，不改動卡組；碰撞中暫時禁止切換，以免中斷演出。

同一設定視窗可選繁體中文、English、日本語、Español。操作、效果、場地規則、演示及戰局訊息隨語言切換；迷因原名、來源證據與玩家自訂內容保留原文。語言獨立儲存，不重置目前對局或改寫卡組。

- **人機對決**：AI 使用相同能量、席位與效果規則。
- **同機雙人**：兩人輪流部署，交接時隱藏下一位玩家的手牌。這是同一裝置的雙人模式，沒有遠端連線配對。
- **生命決勝**：20 LP，歸零落敗；同時歸零為平手。
- **五次擊倒**：先擊倒 5 名對方角色獲勝。
- **自由沙盒**：不消耗能量、不自動結束，可持續測試卡牌組合。

「新對決」可選對手、目標與場地；更換場地會開始新局。每回合最多 3 名角色、2 張陷阱、9 張手牌。首輪雙方各免費登場一名角色、抽 5 張牌並獲得 3 能量。之後每輪抽 1 張，基礎能量逐輪增加至 8。

角色被擊倒時其主人損失 2 LP；碰撞結束後空場再失去 3 LP，雙方皆空場則各失去 1 LP。第 10 輪起每輪額外失去 2 LP，避免生命模式無限拖延。卡牌棄牌堆會在抽牌堆耗盡時重洗。

## 卡牌與連攜

初始提供 **23 張精選卡、100 個 Imgflip 模板、4,807 個全球迷因模板、5 個場地**。所有卡牌免費解鎖，沒有付費抽卡。不同來源可能收錄同一迷因的不同版本；4,807 是全球來源內去重後的模板數，不宣稱為全網全集。

| 類型 | 規則 |
| --- | --- |
| 角色 | 進入戰場，以攻擊、生命、速度參與碰撞 |
| 魔法 | 立即觸發效果，例如傷害、抽牌、補血 |
| 陷阱 | 下一次己方與敵方碰撞時發動一次，優先於普通傷害 |
| 裝備 | 立即增加指定角色屬性，持續至該角色離場 |
| 場地 | 切換全場規則，例如燃燒、加速、護盾或治療 |
| 融合 | 消耗兩名同陣營友軍，繼承陣營與素材一半總攻擊；不計擊倒 |

同時存在兩名同陣營角色會啟動連攜：混沌／暴擊提高碰撞傷害，療癒每輪回血，腦洞多抽牌，財富增加能量，錯亂增加護盾。不同陣營可與卡牌效果疊加。

### 連攜套裝

同一方場上存活的同陣營角色各計 1 件，重複卡也計入；精選、網路及自訂角色都適用。湊齊 3 件時，下列效果與原本 2 件連攜疊加：

| 套裝 | 3 件追加效果 |
| --- | --- |
| 一切都很好／混沌 | 每次碰撞傷害再 +2 |
| 笑著撐下去／療癒 | 每輪全隊再回復 3 生命 |
| 宇宙大腦／腦洞 | 每輪再多抽 1 張，仍受 9 張手牌上限限制 |
| 一起上月球／財富 | 每輪能量再 +1 |
| 全員 BONK／暴擊 | 每名角色每輪首次碰撞對碰撞目標額外造成 3 傷害 |
| 現實出錯了／錯亂 | 每輪全隊護盾再 +3 |

被擊倒或融合消耗的角色不再計件；融合角色依繼承陣營計 1 件。未達門檻時停止後續加成，不收回已獲得的生命、護盾、手牌或能量。回合型效果於下一輪開始結算；BONK 若首次碰撞時未滿 3 件，不會補發。戰場顯示即時計件，展開套裝效果或打開角色詳情可查看規則。

例如 Doge + 不服的貓啟動暴擊，再用史詩握手強化全隊；同陣營角色也可作為究極迷因體的融合素材。每名角色的「首次碰撞」效果每輪重置；陷阱與死亡效果可繼續觸發連鎖擊倒。

## 卡組與創作

在卡牌圖鑑搜尋、篩選並加入卡組。卡組需 10–30 張、至少 1 張角色，每張卡由介面最多加入 2 張。卡組工坊提供 3 套預設流派，以及自訂名稱、HTTPS 圖片、類型、陣營、數值與最多 4 組效果的卡牌編輯器。

滑鼠停留或鍵盤聚焦卡片時，會顯示獨立的效果試演；Esc 可關閉。手機可在卡牌詳情按「播放效果演示」，也可再次按下重播。演示使用相同結算與物理引擎，但在獨立沙盒中使用示範目標，不消耗正式對局的手牌或修改存檔；登場、碰撞、每輪與離場效果分階段呈現。

卡組工坊的「全球隨機套裝」抽選 12 張同陣營全球角色與 8 張支援卡，確認後才取代已存卡組。「每日挑戰」按 UTC 日期決定雙方全球卡組、開局手牌與場地，採 20 LP 規則，不改寫已存卡組；相同卡庫版本與日期可重現同一挑戰。每日挑戰目前沒有線上排行榜。

可用效果包括傷害、治療、護盾、攻擊強化、抽牌與能量；角色可在登場、首次碰撞、每輪開始及死亡時觸發。可選單體或全體目標。數值與場上單位數有上限，以保持瀏覽器運行穩定；不執行玩家提交的 JavaScript。

卡組、自訂卡與勝場保存在目前瀏覽器的 `localStorage`，不跨裝置同步。JSON 匯出／匯入可分享完整卡組。匯入會在確認後取代本機卡組與自訂卡庫，不會覆蓋對戰統計。

## 迷因來源

全球卡庫採用 [templates.meme 公開 API](https://api.templates.meme/api/templates) 的已發布、來源標示 SFW 且具有圖片／影片封面之模板。`src/data/world-memes.json` 保留逐卡來源、語言、地區、能力分類及設計依據。2026-10-02 收集 4,894 筆候選，移除 41 筆重複與 46 筆缺乏可分類依據的記錄，保留 4,807 筆；涵蓋 15 種來源語言與 32 個來源地區，未標註的資料不推測語言或國籍。

能力由 `src/semantics.js` 的 20 種語意規則設計，依正式名稱與來源情緒／主題標籤匹配，不以 ID 雜湊指定數值。這是可追溯的自動化遊戲詮釋，並非每張均經人工考證；來源標籤也可能出錯。搜尋別名可能只是 SEO 字詞，不用於能力分類。圖鑑可依來源語言、地區與梗意能力篩選，卡牌詳情顯示設計依據。沒有足夠梗意資料的新 Imgflip 模板只保留基本角色，不編造特殊效果。

另保留 [Imgflip 公開模板 API](https://api.imgflip.com/get_memes) 的 100 個熱門模板及原有卡牌 ID，避免舊卡組失效。圖鑑的「更新網路卡庫」只更新 Imgflip；全球資料使用下列腳本更新。這不是全網全集，也不能涵蓋所有語言與未來迷因；其他迷因可透過自訂卡牌與 JSON 卡組加入。

圖片由原始 HTTPS 來源載入，未把第三方圖片重新授予 MIT 授權；圖片、角色、商標仍屬其權利人。外部來源失效或被封鎖時，卡牌保留文字及替代圖樣，遊戲規則仍可運行。網站無後端帳號、廣告或付費功能；圖片及字型服務會收到一般瀏覽器資源請求。

更新專案內的模板快照：

```sh
npm run catalog:refresh
npm run catalog:collect
npm run catalog:build
```

收集腳本預設從 `.artifacts/world-crawl` 快取續傳；要重新取得最新索引與資料，使用 `npm run catalog:collect -- --refresh`，完成後執行 `npm run catalog:build`。原始收集快取不提交 Git；只提交經篩選的快照。

## 本機開發

Node.js 22.12+（建議 Node.js 24）。

```sh
npm ci
npm run dev
```

Vite 預設使用 `http://127.0.0.1:5173`。正式版輸出至 `dist/`：

```sh
npm test
npm run build
npm run test:browser
```

Windows 瀏覽器測試使用已安裝的 Microsoft Edge；Linux 使用 Playwright Chromium，先執行 `npx playwright install --with-deps chromium`。可用環境變數 `TEST_BASE_URL` 對已部署網站執行同一套瀏覽器測試。

## 專案結構

- `src/catalog.js`：卡牌、場地、效果資料與匯入驗證。
- `src/semantics.js`、`src/data/world-memes.json`：語意能力與全球卡庫快照。
- `src/game.js`：回合、能量、連鎖效果、AI 與勝負規則。
- `src/physics.js`：固定時間步長的 Matter.js 碰撞模擬。
- `src/arena.js`：Canvas 場地、角色與碰撞特效。
- `src/main.js`、`src/style.css`：介面及操作流程。
- `src/storage.js`：本機存檔與卡組格式驗證。
- `tests/`：規則測試、完整模擬對局及桌面／手機瀏覽器驗證。

靜態網站可部署至任何支援 `dist/` 的主機。Sites 部署使用 `.openai/hosting.json` 的正式環境連結；複製專案時需改用自己的 Sites `project_id`，不要向原專案發布。

## 貢獻
